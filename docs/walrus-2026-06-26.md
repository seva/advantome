# WaLRuS-DATA — 2026-06-26

Session scope: Initial project ingest, Phase 0 redefinition, Phase 1 re-execution against new genome-specific gates.

---

## Wins

- Phase 0 redefined: replaced generic 7-criteria with genome-specific asymmetry framework (5 gates: Signal integrity, Actionability without gatekeeper, Measurement redundancy, Effect size, Net benefit; RAROC 2x2: Self-actionability × Effect size).
- Phase 1 re-executed against new framework: researched 8 candidate asymmetry classes from CPIC, ACMG SF v3.3, PharmGKB, FDA, DTC market, and current literature.
- Each candidate scored against 5 gates. Survivors: PGx, carrier screening, Mendelian. Self-actionable traits and PRS marginal on multiple gates. Nutrigenetics, epigenetic age, ancestry failed.
- Selected **PGx** (pharmacogenomics) as target. Rationale: only candidate that passes all 5 gates. 319 CPIC gene-drug pairs, 34 genes, 164 drugs. Non-redundant, large effect, strong net benefit.

## Learnings

- The original Phase 1 was scored against the old 7-criteria framework (designed for acquired asymmetries). Under the new genome-specific gates, the same selection (PGx) holds, but the reasoning is different — what matters is not "rare" or "hard to copy" but signal integrity + non-redundancy + effect size + actionability + net benefit.
- Carrier screening passes all 5 gates but was rejected for narrow actionability window. This is a judgment call — carrier screening could be selected as a secondary target if the project scope expands.
- PGx gatekeeper dependency is real but the logic holds: the asymmetry exists in the genome regardless of knowledge. The bear controls the initiation of action (bringing results to a prescriber).

## Risks

- PGx gatekeeper dependency: if prescribers ignore PGx data (low clinical adoption is well-documented), the asymmetry is latent rather than active. The asymmetry exists but is not exploited.
- ACMG SF v3.3 (2025) now includes 84 genes with some overlap with PGx (e.g., GLA for Fabry has both diagnostic and pharmacogenomic implications). Boundary between categories is blurring.

## Strategy

- Phase 2 is the PGx interpretation engine: translate raw genotype (VCF/23andMe format) into CPIC-guided metabolizer phenotypes and actionable prescribing guidance.
- Phase 2 should address the gatekeeper dependency head-on: design for the bearer first (education, consultation support, prescriber referral).

## Decisions

- PGx selected as primary target over carrier screening. Carrier screening rejected because the asymmetry window is narrow (reproductive) and compounding is low (once exploited, value is exhausted).
- Post-phase audit: ARCHITECTURE.md still empty — Acceptable (no implementation code). No uncovered lines to classify. No placeholder content beyond the empty architecture sections.
- Previous WaLRuS for this date replaced because Phase 1 has been re-executed from scratch against the new framework.

## Alignment

- Phase gate: Phase 1 discovery is a hard prerequisite for Phase 2 (implementation). Architecture will be defined in Phase 2 when component interfaces become concrete.
- Session protocol observed: CLAUDE.md read, checkboxes scanned, issues checked, memory searched.

## Tradeoffs

- Selecting a gatekeeper-dependent asymmetry (PGx) trades immediate self-actionability for larger effect size and wider applicability. Carrier screening would offer self-actionability but narrow window.
- Keeping ARCHITECTURE.md empty is fine: no code exists to document. Will be populated in Phase 2.

## Alternatives

- **Carrier screening** was the strongest alternative. Self-actionable, high signal integrity, very large effect. Rejected because narrow window.
- **Rejecting all and selecting none** was considered but the asymmetry is real enough to warrant further work. The gatekeeper risk is manageable through product design.
