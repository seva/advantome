## Wins

- Phase 1 completed: genome asymmetry catalog with 7 signal classes evaluated, PGx selected as target.
- Phase 0 redefined: replaced generic 7-criteria framework (designed for acquired asymmetries) with genome-specific asymmetry framework. New discriminators: Signal integrity, Actionability without gatekeeper, Measurement redundancy, Effect size, Net benefit. New RAROC 2x2: Self-actionability x Effect size.
- Post-phase audit conducted. Gaps identified and closed: CLAUDE.md updated, IMPLEMENTATION.md updated, Phase 0 committed.

## Learnings

- The original 7-criteria framework (Valuable, Rare, Hard to copy, Exploitable, Compounding, Context-fit, Legible) was designed for acquired asymmetries. For genome-derived asymmetries, three criteria are effectively constants (Rare, Hard to copy, Compounding) and do not discriminate between candidates.
- "Hard to copy" for genome traits is biological exclusivity — not market inimitability. The Phase 1 initial scoring treated it as "anyone can buy a 23andMe kit," which conflates data access with biological endowment.

## Risks

- Phase 1 was never re-executed against the new genome-specific framework. The artifact still scores against the old 7 criteria. It may select a different target under the new gates.
- No implementation language or runtime declared. ARCHITECTURE.md is still empty at the component/interface level.

## Strategy

- Next step depends on whether Phase 1 target holds under the new framework. If PGx survives re-evaluation, Phase 2 is the PGx interpretation engine. If not, Phase 1 must be redone.

## Decisions

- Phase 0 framework split: general criteria retained for context, genome-specific framework added as the primary evaluation tool for this project. The five genome-specific gates replace the seven general criteria when scoring asymmetries.
- Phase 0 artifact rewritten in place (not versioned alongside original). Historical original lives in git history (df20b1c).
